# Airlines-EDA-Project
EDA project analyzing airlines flights data using Python and data visualization.

## Dataset
Columns include:

- **airline** – Name of the airline  
- **flight** – Flight code  
- **source_city** – Departure city  
- **departure_time** – Scheduled departure  
- **stops** – Number of stops  
- **arrival_time** – Scheduled arrival  
- **destination_city** – Destination city  
- **class** – Travel class  
- **duration** – Flight duration (hours)  
- **days_left** – Days left before departure  
- **price** – Ticket price  

---

## Analysis Performed
1. Airline frequencies  
2. Departure & arrival time distributions  
3. Source & destination city distributions  
4. Price variations by airline  
5. Price vs departure/arrival times  
6. Price vs source/destination cities  
7. Price impact for tickets booked 1–2 days before departure  

---

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
